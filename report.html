1. Executive Summary & Core Philosophy

AlphaCondor is an autonomous, production-grade algorithmic options trading agent designed for Alpaca's developer platform. It operates a dual-strategy options income engine:

  • The Core Wheel Strategy (Cash-Secured Puts ↔ Covered Calls): Systematic cash-secured options writing across fundamentally sound blue chips (AAPL, MSFT, NVDA, SOFI, SPY) targeting 20%–35% annualized theta decay.
  • 0DTE Iron Condors (SPY): High-capital-efficiency defined-risk credit spreads exploiting rapid same-day expiration decay with 10x–20x lower margin requirements ($500 spread margin vs. $30,000+ per CSP contract).

The foundational design principle is the strict decoupling of Generative AI cognition from deterministic risk enforcement. An LLM acts as an advisor and analyst, while an immutable Python mathematical layer acts as the execution firewall.

2. AI Cognition & Reasoning Layer

The cognitive engine utilizes Google Gemini (gemini-3.5-flash-lite) via the modern google-genai SDK.

  • Context Bundle Synthesis: Prior to reasoning, the perception engine aggregates Wilder's RSI(14), 20/50/200 EMAs, ATR-14, Bollinger Bands, Black-Scholes IV Rank, top candidate option contracts, and news sentiment into a dense structured context.
  • Strict Schema Enforcement: The prompt mandates a strict Pydantic JSON schema (OptionTradeSignal) guaranteeing machine-parseable outputs containing proposed action, target strike, DTE, limit price, confidence score (0.0–1.0), and natural language rationale.
  • Failsafe Offline Fallback: In the event of API timeout or network partition, the agent automatically falls back to an internal quantitative ruleset without crashing or halting active position monitoring.

3. The 7 Deterministic Risk Gates (The Safety Firewall)

Generative models can hallucinate strikes or propose dangerous leverage. AlphaCondor eliminates this risk by mandating that every AI trade signal must pass 7 immutable mathematical checks before broker submission:

Gate Verification Target Mathematical Enforcement
1. Confidence Floor Model Certainty Rejects any trade where AI confidence is below 70%.
2. Concurrency Cap Portfolio Capacity Limits simultaneous active option positions to a maximum of 20.
3. Cash Collateral Cash-Secured Check Guarantees 100% cash backing for puts: $\text{Strike} \times 100 \times \text{Qty} \le \text{Cash}$.
4. Concentration Cap Single Ticker Limit Restricts individual underlying allocation to a configured portfolio percentage.
5. Share Backing Covered Call Rule Requires holding $\ge 100$ shares of underlying. Naked calls are mathematically impossible.
6. Phase Consistency Wheel State Machine Enforces strict state transitions (cannot sell call without shares; cannot duplicate open puts).
7. Liquidity & Spread Execution Quality Filters illiquid options with bid-ask spread > 15% or prices $\le \$0.05$.

4. Automated Position Lifecycle Management

  • 50% Profit Target: Automatically submits buy-to-close orders once 50% of the maximum credit is captured, accelerating capital velocity and avoiding long-tail tail risk.
  • 21 DTE Gamma Roll Rule: Closes or rolls open monthly contracts at 21 DTE to eliminate exponential assignment volatility.
  • 200% Stop Loss: Caps catastrophic downside by liquidating positions if unrealized losses exceed 200% of received premium.
  • 3:45 PM EOD Forced Exit: Closes 0DTE Iron Condors 15 minutes before market close to eliminate after-hours pin risk.

5. Alpaca Developer Stack Integration

  • Alpaca Trading API (alpaca-py): Native order routing with explicit PositionIntent (SELL_TO_OPEN, BUY_TO_CLOSE, BUY_TO_OPEN, SELL_TO_CLOSE).
  • Alpaca Market Data API: Historical daily bars, stock quotes, and option chains with analytical Greeks.
  • Alpaca TradingStream: Asynchronous WebSocket client streaming real-time trade fills and cancellations.
  • Alpaca MCP Server: Configured via mcp_config.json running uvx alpaca-mcp-server for Claude/Cursor conversational trading.
  • Streamlit Web Dashboard: Real-time portfolio monitoring, open positions table, trade history, and equity curve (localhost:8501).
  • Rich CLI: Terminal management with alphawheel run / status / history / analyze / condor.
